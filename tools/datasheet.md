# 반려견 음식 판단 데이터 시트

Nov 6, 2026 · @동주

## MVP 기능 정의

견주의 질문 "줘도 돼? 얼만큼? 어떻게? 먹었으면 어떡해?"에 하나씩 답하는 4개 기능으로 MVP를 잡는다.

| 기능 | 답하는 질문 | 내용 |
| --- | --- | --- |
| 1. 음식 검색 + 많이 묻는 음식 | 줘도 돼? | 부위·상태별로 나뉜 결과(예: 김 → 맨김 / 조미김). 홈 상단에 많이 묻는 음식을 노출하되, 출시 초기엔 "착각하기 쉬운 음식" 큐레이션, 검색이 쌓이면 실제 검색 순위로 전환. 계절 음식 묶음(11월: 귤·고구마·감) |
| 2. 판정 카드 | 얼만큼? 어떻게? | 4단계 판정, 체중별 적정량, 조리 방법, 주의사항, 근거 출처를 한 화면에 |
| 3. 반려견 프로필 | 우리 아이 기준으로는? | 체중으로 적정량 구간 자동 선택, 신장·췌장 질환 체크 시 판정 한 단계 하향과 이유 표시 |
| 4. 먹었을 때 대처 | 먹었으면 어떡해? | 금지 음식 카드의 "이미 먹었어요" 버튼 → 응급 증상·대처 → 근처 동물병원 연결 |

**1차 목표 (포트폴리오 범위):** 위 4개 기능만으로 실제 배포 가능한 모바일 우선 웹사이트. 로그인 없이 프로필은 브라우저에 저장한다.

**2차 목표 (확장, 이번 범위 제외):** 앱다운 경험으로 확장 — 사진·바코드 인식, 식단 기록과 칼로리 누적, 계정·알림, 커뮤니티.

## 데이터 시트

## 목적

음식 약 70개를 같은 기준으로 판정해, 서비스가 "줘도 돼? 얼만큼? 어떻게?"에 한 번에 답할 수 있는 데이터를 만든다. 범용 AI와의 차별점은 이 시트의 세밀함(부위·생/익힘·양)과 근거 출처에서 나온다.

- 한 음식이라도 상태나 부위가 다르면 **행을 나눈다** (예: 생고구마 / 찐 고구마, 닭가슴살 / 닭발 / 익힌 닭뼈).
- 판정은 근거 자료로 확인한 뒤에만 채운다. 해외 자료로 확인하지 못한 행은 보수적으로 판정하고 근거에 "확인 필요"를 남긴다.
- 11/6 1차 작성 완료, 주말에 "확인 필요" 행을 검증하고 11/9 기능·화면 설계에 바로 쓴다.

## 판단 기준 항목

음식 한 행마다 아래 9개 항목을 채운다.

| 항목 | 채우는 내용 | 예시 |
| --- | --- | --- |
| 음식명 | 사용자가 검색할 이름 | 고구마 |
| 부위·형태 | 같은 재료라도 갈리는 부위나 형태 | 과육 / 껍질 / 씨, 가슴살 / 닭발 |
| 상태 | 생 / 익힘 / 건조 / 가공 | 생, 찐 것 |
| 판정 | 4단계 등급 (아래 기준) | 조건부 가능 |
| 적정량 | 체중 구간별 1회·1일 양 (아래 기준) | 소형견 1\~2조각 |
| 조리 방법 | 안전하게 주는 방법 | 껍질 벗겨 푹 찐 뒤 식혀서 |
| 주의사항 | 양념, 질환, 과다 섭취 시 증상 | 당뇨·비만견은 피하기 |
| 먹었을 때 대처 | 위험 음식일 때만 | 즉시 동물병원 연락 |
| 근거 출처 | 확인한 자료 링크 | ASPCA 등 |

## 판정 등급과 적정량 기준

판정은 4단계로 나누고, 가능·조건부 가능일 때만 적정량과 조리 방법을 채운다. 췌장염 예방을 위해 비계·껍질·기름진 부위와 지방이 많은 가공육은 소량이라도 모두 금지로 둔다.

| 등급 | 뜻 | 적정량 칸 |
| --- | --- | --- |
| 가능 | 조리 방법만 지키면 줘도 됨 | 채움 |
| 조건부 가능 | 특정 상태·부위·소량일 때만 됨 | 채움 + 조건 명시 |
| 주의 | 소량은 괜찮을 수 있으나 권장하지 않음 | 비움, 주의사항에 이유 |
| 금지 | 소량도 위험 | 비움, 먹었을 때 대처 필수 |

적정량은 하루 기준 추정치다. 간식 전체를 하루 칼로리의 10% 이내로 두라는 수의영양 가이드([UC Davis](https://healthtopics.vetmed.ucdavis.edu/node/916), [AKC](https://www.akc.org/expert-advice/health/how-many-treats-can-dog-have/))에서 출발해, 음식 하나는 그 예산의 절반만 쓰도록 계산했다. 하루 간식 예산은 소형(5kg) 약 35kcal, 중형(15kg) 약 85kcal, 대형(30kg) 약 140kcal로 잡았고, 음식별 칼로리는 일반 식품 영양 정보의 근사치다. 처음 주는 음식은 표의 절반부터 시작한다.

| 구간 | 체중 |
| --- | --- |
| 소형견 | 10kg 미만 |
| 중형견 | 10\~25kg |
| 대형견 | 25kg 이상 |

## 질환견 주의 기준

신장이 안 좋은 강아지는 **인·단백질·나트륨**, 췌장이 안 좋은 강아지는 **지방**을 줄여야 해서, 음식 목록에서 "가능"인 음식도 판정이 한 단계 내려간다. 질환견은 아래 표의 피할 음식을 "주의"로 보고, 괜찮은 간식도 수의사와 양을 정한다.

| 질환 | 줄여야 할 성분 | 이 시트에서 피할 음식 | 비교적 괜찮은 간식 | 근거 |
| --- | --- | --- | --- | --- |
| 신장 질환 | 인(가장 중요), 단백질, 나트륨 | 고기·내장 전반(닭가슴살, 소·돼지·오리, 간·허파·염통), 생선, 치즈, 빵, 햄·소시지, 순대, 황태·북어·멸치·김(소금), 장조림 | 수박, 사과, 바나나, 블루베리, 당근, 브로콜리 | [Tufts 수의영양](https://vetnutrition.tufts.edu/?p=8560), [Tufts 신장 간식](https://sites.tufts.edu/petfoodology/?p=9316), [VCA](https://vcahospitals.com/knowles-central/know-your-pet/nutrition-for-dogs-with-chronic-kidney-disease) |
| 췌장 질환 (췌장염 이력) | 지방 | 차돌박이, 삼겹살, 족발, 보쌈 비계, 도가니, 햄·소시지, 순대, 방어회, 고등어, 오리 껍질, 치즈, 달걀 노른자, 땅콩·땅콩버터, 아몬드, 호두, 아보카도, 모닝빵·크림빵 | 지방이 적은 채소·과일, 껍질·기름 뺀 닭가슴살 소량 | [Hill's 수의사 안내](https://www.hillsvet.com/content/dam/cp-sites/hills/hills-vet/en_us/client-information-series/digestive-system/pancreatitis_en.pdf), AKC-음식, ASPCA |

- **신장 질환견 간식 기준:** 열량 100kcal당 인 150mg, 나트륨 100mg 미만이 대략적인 출발점이다(Tufts).
- **췌장 질환견:** 한 번의 기름진 음식으로도 재발할 수 있어, 사람 음식 조각을 특히 조심한다.
- **서비스 반영:** 프로필에 질환을 등록하면 해당 음식의 판정을 자동으로 한 단계 낮추고 이유를 함께 보여준다.
